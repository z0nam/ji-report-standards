# 연구보고서 서식 안내 (JRI 표준)

작성일: 2026-06-01
적용 범위: JRI 정책연구 본보고서 md 초안 및 hwpx 최종편집

## 워크플로우

* 작성 단계: md → gdoc → hwpx 최종편집
  - md 단계에서는 표준 마크다운 문법 준수가 핵심
  - 중간 형식별 호환성 고려는 불필요 (각 단계 자동 변환)

## 장·절 구조

* 헤딩에 번호를 직접 달지 않음 — 템플릿이 자동 부여함 (작성 시에는 제목만 씀)
  - 장 번호: 로마자 대문자 (`Ⅰ`, `Ⅱ`, `Ⅲ`, `Ⅳ`) 형식으로 자동 부여
  - 절 번호: `1-1`, `1-2` 형식으로 자동 부여 (JRI 정책연구 표준)
* 깊은 헤딩(`####`) 사용 금지
  - md 본문 구조는 `#` (장) → `##` (절) → 본문/bullet 까지로 한정
  - 더 세분이 필요한 경우 소절(`###`)까지 허용

## 캡션 형식

* 캡션 framing(`<표 Ⅰ-1>` · `[그림 Ⅰ-1]`)은 템플릿이 자동 부여함 — md 캡션에는 **제목만** 적고 framing은 직접 타이핑하지 않음
  - 잘못된 예: `<표 부록-1> 참여자 효과 자료 신뢰도 등급` (자동 framing과 충돌해 `<표 부록-1> <표 부록-1> 참여자 효과 …`로 이중 출력됨)
  - 옳은 예: `참여자 효과 자료 신뢰도 등급` (도구가 `<표 부록-1>` framing을 자동 부착)
  - 동일 원칙이 헤딩 번호 자동 부여(「장·절 구조」)에도 적용됨 — 번호와 framing은 모두 도구가 관리함
* 렌더링된 framing 형식
  - 표 캡션: `<표 Ⅰ-1>` 형식
  - 그림 캡션: `[그림 Ⅰ-1]` 형식
* 캡션 본문은 명사형으로 끝남
  - 예: "〜 전망", "〜 현황", "〜 효과"
  - 동사형·서술형 종결("〜를 보여줌", "〜를 정리한다") 금지

## 장 도입 블록

* 각 章 제목 바로 아래에 「장 도입 블록」 배치
  - 위치: 章 제목(`# …`) 바로 아래, 첫 節 제목보다 위
  - 형식: 톤 가이드(`tone/latest.md`)의 2단 bullet 규칙 적용
  - 역할: 본 장의 범위·접근 방식·자료원·결과 윤곽 사전 안내
* 첫 절의 「개요」 항과 역할 중복 회피
  - 도입 블록: 장 전체 윤곽
  - 「개요」 항: 첫 절의 진입 설명

## 표·그림 처리

* md 단계에서 표는 마크다운 표 문법으로 작성
* hwpx 단계에서 hwp 표 양식으로 변환
* 그림은 md 단계에서 이미지 링크 또는 캡션만 명시, hwpx 단계에서 삽입

## 표 상호참조 (선택)

* 본문에서 표를 지칭할 때 어느 표인지 분명히 가리키기 위해 상호참조 토큰을 사용할 수 있음
  - 캡션에 라벨 선언: 표 위 캡션 줄 끝에 `{label:안정적_id}` 부착
  - 본문에서 참조: `{ref:안정적_id}` 호출
  - 변환 도구가 fill 시점에 실제 번호(예: `<표 Ⅱ-1>`)로 치환함
  - id는 의미를 드러내는 짧은 영문 snake_case 권장 (예: `tbl_grade`, `tbl_sensitivity`)
  - 단일 중괄호 토큰임 — 템플릿의 이중 중괄호 토큰(`{{appendix}}`, `{{table_template}}` 등)과 다름
* 본 기능은 필수가 아니며, 사용 여부는 작성자가 결정함
  - AI 도구는 md 생성을 시작하기 전에 상호참조 토큰 사용 여부를 작성자에게 질문함
  - 작성자가 상호참조 개념에 익숙하지 않으면 "사용 안 함"으로 답하도록 안내함
  - 미사용 시 본문에서 표를 가리킬 때는 자연스러운 한국어 문맥으로 식별함 (예: "아래 표와 같이 〜", "위의 등급표에 의하면 〜")
* 도구별 지원 — `hwp-agent write`가 `{label}` / `{ref}` 토큰을 인식하여 자동 치환함
  - 미해결 ref나 중복 라벨은 fill 시점 경고로 노출됨
