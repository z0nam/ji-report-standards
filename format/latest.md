# 연구보고서 서식 안내 (JRI 표준)

작성일: 2026-05-12
적용 범위: JRI 정책연구 본보고서 md 초안 및 hwpx 최종편집

## 워크플로우

* 작성 단계: md → gdoc → hwpx 최종편집
  - md 단계에서는 표준 마크다운 문법 준수가 핵심
  - 중간 형식별 호환성 고려는 불필요 (각 단계 자동 변환)

## 장·절 구조

* 헤딩에 번호를 직접 달지 않음 — 템플릿이 자동 부여함 (작성 시에는 제목만 씀)
  - 장 번호: 로마자 대문자 (`Ⅰ`, `Ⅱ`, `Ⅲ`, `Ⅳ`) 형식으로 자동 부여
  - 절 번호: `1-1`, `1-2` 형식으로 자동 부여 (JRI 정책연구 표준)
* 깊은 헤딩(`####`) 사용 금지
  - md 본문 구조는 `#` (장) → `##` (절) → 본문/bullet 까지로 한정
  - 더 세분이 필요한 경우 소절(`###`)까지 허용

## 캡션 형식

* 표 캡션: `<표 Ⅰ-1>` 형식
* 그림 캡션: `[그림 Ⅰ-1]` 형식
* 캡션 본문은 명사형으로 끝남
  - 예: "~ 전망", "~ 현황", "~ 효과"
  - 동사형·서술형 종결("~를 보여줌", "~를 정리한다") 금지

## 장 도입 블록

* 각 章 제목 바로 아래에 「장 도입 블록」 배치
  - 위치: 章 제목(`# …`) 바로 아래, 첫 節 제목보다 위
  - 형식: 톤 가이드(`tone/latest.md`)의 2단 bullet 규칙 적용
  - 역할: 본 장의 범위·접근 방식·자료원·결과 윤곽 사전 안내
* 첫 절의 「개요」 항과 역할 중복 회피
  - 도입 블록: 장 전체 윤곽
  - 「개요」 항: 첫 절의 진입 설명

## 표·그림 처리

* md 단계에서 표는 마크다운 표 문법으로 작성
* hwpx 단계에서 hwp 표 양식으로 변환
* 그림은 md 단계에서 이미지 링크 또는 캡션만 명시, hwpx 단계에서 삽입
