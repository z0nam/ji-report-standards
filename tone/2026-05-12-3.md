# 본보고서 작성 톤 및 bullet 위계 규칙

작성일: 2026-05-12
적용 범위: `90.최종보고서/` 하위 본보고서 md 초안 전체
레퍼런스:
* JRI 정책연구 2024-18 「에너지 대전환 시나리오에 따른 지역경제 효과분석」(강영준·윤형석, 2024)
* 본 보고서 서식 docx: `report/final/연구보고서_서식_2장3장_조남운.docx`

## 규칙

* 번호가 붙는 개요체계는 장-절-소절까지만 사용하고 소절보다 낮은 넘버링은 사용하지 않음 
  * hwpx 편집편의를 위해 1.1.1 체계를 사용함
* 일반문장은 사용하지 않고 2단 bullet 으로만 사용
* 종결어미는 음슴체 (예: "검토함", "전망됨", "기대됨", "한계가 뚜렷함"). 다체("~한다", "~이다")나 합쇼체("~합니다") 모두 금지.
* 음슴체 끝 마침표는 쓰지 않음
* bullet은 **2단계 위계로만** 표현. 메인 bullet과 부연 bullet 두 단계까지만 사용함. 3단 이상 들여쓰기는 금지.
  * 마커는 `*`로 통일.
  * 메인 bullet들만 순서대로 읽어도 스토리·논리가 완결되어야 하고, 부연 bullet은 설명·예시·근거가 필요할 때만 씀.
* 각 장은 章 제목 바로 아래에 「장 도입 블록」을 배치함
  * 도입 블록은 본 장이 다루는 범위·접근 방식·주요 자료원·결과의 윤곽을 독자에게 사전 안내함
  * 위치는 章 제목(`# 제Ⅱ장 …`) 바로 아래, 첫 節 제목(`## Ⅱ-1절 …`)보다 위
  * 도입 블록도 본 규칙에 따라 2단 bullet으로 표현함 (일반 산문 단락 금지)
* 깊은 헤딩(`####`)·bold strong 같은 markdown 장식은 최소화. 절 번호는 `1-1`, `1-2` 형식 (JRI 정책연구 표준).
* 표·수식·인용은 그대로 사용. 표 캡션은 `<표 Ⅰ-1>` 형식, 그림 캡션은 `[그림 Ⅰ-1]` 형식. 캡션 본문은 명사형으로 끝남 ("〜 전망", "〜 현황", "〜 효과").
* 표·그림 제시 시 본문에 해석·설명이 반드시 동반되어야 함
  * 표/그림만 단독 제시하고 끝내는 것 금지
  * 본문에서 핵심 발견·시사점·근거 활용 방식을 명시
  * 권장 위치: 표/그림 직전 도입(예: "…는 〈표 Ⅱ-1〉과 같음") 또는 직후 해석(예: "〈표 Ⅱ-1〉에서 보듯이 …")
* 기간·범위 표기는 ASCII 물결표(`~`) 사용 금지
  * 마크다운 파서가 취소선(`~text~`)으로 해석할 위험 있음
  * 전각 물결표 `〜` (U+301C) 사용
  * 예: "2020〜2024년", "1〜2개", "기준연도〜목표연도"
* 금액 단위는 맥락에 따라 선택
  * 직관적 가독성이 우선될 때: 만 원, 억 원 사용 (예: "예산 5,500만 원", "총사업비 100억 원")
  * 재정·회계적 정확성이 우선될 때: 천 원, 백만 원 사용 (예: "예산 55,000천 원", "총사업비 10,000백만 원")
  * 영문 약어 `M`, `k`는 전문 영역(기술·금융 등)에서만 사용

## 적용 시 주의

* 챕터별 md(`01_서론.md` 〜 `08_결론.md`) 작성·수정 시 항상 본 규칙을 검사함.
* 장 도입 단락은 첫 절(1절)의 「개요」 항(1-1 개요)과 역할이 중복되지 않도록 함. 도입 단락은 장 전체 윤곽, 1-1 개요는 첫 절의 진입 설명에 한정.
* 메타 문서(목차안, 자료 매핑, 작업 계획)는 본문 prose 부분만 음슴체 적용. 목차 항목 자체(체언으로 끝나는 제목)는 톤 적용 대상이 아님.
* 외부 인용문(수행계획서, 회의록 등)은 출처 명시 후 원문 톤 유지 가능. 본 컨텍스트에서 새로 생성하는 본문은 무조건 본 규칙 적용.
* gdoc 이관 후에는 markdown bullet 위계가 gdoc 들여쓰기 위계로 변환되므로, md 단계에서 위계가 어긋나면 gdoc 단계에서 수정 비용이 커짐.
